# 部署与备份

## 本机生产运行

```powershell
npm ci
npm run build
npm start
```

默认端口为 3000。终端输出的本机地址用于部署电脑，Network 地址用于同网设备。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `ASTRAREADER_DATA_DIR` | `./data` | SQLite、书籍和临时上传目录 |
| `ASTRAREADER_MAX_UPLOAD_MB` | `500` | 单本最大上传 MiB |
| `PORT` | `3000` | Next.js 监听端口 |

## 网络边界

首版没有认证。绑定 `0.0.0.0` 后，同一局域网内任何能访问端口的设备都可以：

- 查看全部书籍和阅读数据。
- 上传、修改和永久删除书籍。
- 读取全部原始文件。

只应在可信家庭或个人网络使用。禁止端口转发到公网；如果必须跨网络访问，应先增加 HTTPS、身份认证和访问审计，而不是直接暴露当前服务。

## 备份

1. 停止 AstraReader 服务。
2. 复制整个 `data/` 目录到另一个磁盘。
3. 恢复时把备份目录放回原位置。
4. 启动服务并打开书库验证。

SQLite 运行期间可能处于 WAL 状态，因此不要在服务运行时只复制 `astra.db`。

## 升级

1. 备份 `data/`。
2. 拉取新代码。
3. 执行 `npm ci`。
4. 执行 `npm run build`。
5. 重启 `npm start`。

数据库迁移会在首次访问时幂等执行。升级后先验证一本 TXT 和一本 EPUB 的阅读进度。

# AstraReader 使用指南

## 适用场景

AstraReader 是单用户、本地运行的网页阅读器。书库、原始电子书、封面、进度、
书签和阅读统计都保存在运行服务的电脑上。

当前支持：

- TXT 和 EPUB。
- EPUB 内置封面与 TXT 占位封面。
- 分页阅读与上下滚动阅读。
- 目录、搜索、书签、进度续读和阅读统计。
- 字体、字号、行距、段距、版心、对齐、主题和翻页动画。
- Windows PowerShell 中的本地生产运行。

## 启动服务

首次使用：

```powershell
npm ci
npm run build
npm start
```

打开：

```text
http://127.0.0.1:3000
```

生产模式修改代码后，需要重新执行 `npm run build` 并重启 `npm start`。

## 导入图书

1. 在书架页选择导入。
2. 选择 TXT 或 EPUB 文件。
3. 确认标题、作者、简介、语言、出版社和出版日期。
4. 导入完成后从书架打开图书。

注意：

- 相同 SHA-256 的文件不能重复导入。
- 单本文件默认上限为 500 MiB。
- TXT 会尝试识别 UTF-8、UTF-16、GB18030 和 Big5。
- 损坏、加密或受 DRM 保护的 EPUB 可能无法读取。

## 书库管理

书架上可以：

- 按最近阅读、标题或加入时间排序。
- 按标题、作者或原始文件名搜索。
- 编辑图书信息。
- 更换封面。
- 永久删除图书及其进度、书签和缓存。

没有用户可见回收站。删除前应确认需要保留原始电子书。

## 阅读工具栏

阅读页顶部工具栏提供：

- 打开左侧目录抽屉。
- 上一页和下一页。
- 添加当前位置书签。
- 进入或退出全屏。
- 打开阅读设置。

目录抽屉包含目录、书内搜索和书签三个面板。

## 阅读设置

### 字体与排版

- 字体：宋体、黑体或楷体。
- 字号：14 到 32px。
- 行距：1.4 到 2.2。
- 段距：0 到 2em。
- 版心宽度：520 到 980px，最终还会受浏览器窗口宽度限制。
- 文本对齐：两端对齐或左对齐。

EPUB 的书籍内嵌样式可能自带字号、段距或行高。阅读器会用用户设置覆盖正文行距，
但保留图片、表格和标题的必要布局。

### 页面主题

内置主题：

- 纸白
- 米黄
- 护眼
- 深灰
- VS Code 深灰
- 纯黑
- 自定义背景和文字颜色

主题设置保存在当前浏览器。书架、阅读正文、目录抽屉和设置面板会同步主题，
但不同设备的主题可以不同。

### 翻页方式

- 滑动：下一页向前滑入。
- 淡入：下一页淡入。
- 关闭：关闭页面切换动画。
- 上下滚动：按纵向连续阅读，右侧悬浮滚动条不占用正文宽度。

分页模式支持：

- `←` / `→`
- `PageUp` / `PageDown`
- `Space` / `Shift + Space`

上下滚动模式还支持 `↑` / `↓`。触摸设备可左右滑动切换分页。

## 进度与位置恢复

EPUB 使用 CFI，TXT 使用字符偏移保存阅读位置。

EPUB 的最后一个 CFI 可能覆盖同一章的多页，因此阅读器还会记录章节内实际滚动
比例：

- 修改字号、行距、段距或版心后，保持相近页内位置。
- 窗口尺寸改变后，保持相近页内位置。
- 分页与上下滚动切换时，保持相近页内位置。
- 保存进度为 100% 时，打开到真正最后一页。

如果自动分栏校验连续失败，阅读器会显示错误，而不是继续显示可能不完整的内容。

## 数据与隐私

默认数据目录：

```text
data/
├─ astra.db
├─ books/
└─ imports/
```

可以使用 `ASTRAREADER_DATA_DIR` 指向项目外的长期数据目录。

安全边界：

- 当前没有登录、用户或权限系统。
- 监听 `0.0.0.0` 后，同一局域网内能访问端口的设备都可以读取和修改数据。
- 不要做公网端口转发。
- 跨网络访问前应先增加 HTTPS、身份认证和访问控制。

备份和恢复步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 内容完整性

项目对当前书库做过逐 spine、逐页、逐字符审计，并在运行时加入资源加载后的分栏
校验。审计范围、结果和已知边界见 [CONTENT-AUDIT.md](CONTENT-AUDIT.md)。

如果发现缺字、末页缺失或页面跳转：

1. 确认运行的是最新构建。
2. 刷新页面并重新打开图书。
3. 检查浏览器控制台是否有 `EPUB layout guard rebuilding columns`。
4. 尝试切换字号、行距或版心，让分栏重新计算。
5. 按 [TROUBLESHOOTING.md](TROUBLESHOOTING.md) 收集诊断信息。

不要通过修改书籍文件来规避问题；先确认原始 EPUB 和当前运行构建。

# EPUB 内容完整性审计

## 审计范围

本次审计针对当前书库中的 EPUB 副本，使用独立数据目录和独立 Playwright
浏览器执行，不修改用户正在阅读的原始文件或进度。

审计目标：

- 按 OPF `spine` 顺序提取 EPUB 原始章节内容。
- 按 EPUB.js 实际渲染顺序逐节读取阅读器正文。
- 对比文本、图片元素数量和分页边界。
- 检查新书默认页、已有进度恢复和上下滚动模式。

## 方法

原始内容提取：

1. 在浏览器中解包 EPUB 的 `META-INF/container.xml` 和 OPF。
2. 按 `itemref` 顺序读取每个 spine 文档。
3. 移除 `script`、`style`、`noscript`、`template`。
4. 对正文执行 NFKC 规范化和空白移除，保留所有非空白字符。
5. 统计每个 spine 项的 `img` 元素数量。

渲染内容提取：

1. 从 EPUB 书脊第一项开始，通过阅读器真实翻页/章节切换路径逐项读取。
2. 从 EPUB.js iframe 的 `body.textContent` 中执行相同的规范化。
3. 读取每个章节的 `img` 数量。
4. 检查分页步长是否为“实际列宽 + 栏间距”，并验证连续翻页后的边界。

规范化只忽略空白差异，不忽略文字、标点、数字或章节顺序。

## 结果

当前 EPUB：

| 指标 | 结果 |
| --- | ---: |
| spine 项 | 44 |
| 有文本的 spine 项 | 22 |
| 规范化正文字符 | 112,265 |
| 图片元素 | 33 |
| 文本一致的章节 | 44 / 44 |
| 图片数量一致的章节 | 44 / 44 |
| 分页步长与边缘边界 | 通过 |
| 缺失或额外文本 | 0 |

审计还确认：

- 新书没有历史进度时，书脊第一项为封面，阅读器显示封面且进度为 0%。
- 已有 CFI 进度可以恢复，进度不会被新书默认页规则强制覆盖。
- 分页模式每个可见页的滚动步长与列宽一致。
- 上下滚动模式可以连续滚动，并通过 CFI 回写位置。
- 阅读设置中的“上下滚动”在 320px 窄屏下保持单行。

## 边界说明

本审计比较的是 EPUB 正文 DOM 与阅读器实际渲染 DOM 的文本和图片数量，不是
逐像素图像比对；CSS 背景图、字体字形细节和受 DRM 保护的资源不在比较范围内。
对于文字章节，规范化后逐字符一致；对于图片章节，图片元素数量一致。

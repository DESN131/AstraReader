# 变更记录

## 2026-11-22

### EPUB 排版

- 将阅读器行距规则应用到正文全部元素，覆盖 EPUB 自带的段落和 class
  行高样式；分页与上下滚动模式均会实时重排。
- 修复末章 CFI 重复导致进度提前显示 100% 的问题；末节按实际分页/滚动偏移
  计算进度，历史记录为 100% 时重新打开会恢复到真正最后一页。

## 2026-11-20

### 阅读稳定性

- EPUB 分页改为真实 32px 栏间距，并同步修正内部列宽与页步长，修复翻页时左侧重复、右侧裁切和内容漏过的问题。
- 新书没有历史进度时从 EPUB 书脊第一项打开，不再自动跳过封面；已有进度仍按原 CFI 恢复。
- 字号、行距、段距或版心变化后强制按当前 CFI 重建视图，修复 EPUB 重新排版后容器宽度未同步的问题。
- 增加 EPUB 和 TXT 的上下滚动阅读方式；滚动位置通过 CFI 或字符偏移回写进度。
- 修复“上下滚动”在阅读设置中换行的问题。
- 在分页视口和纸张边框之间增加安全边距，避免文字贴边或相邻页边缘露出。
- 移除会遮挡正常首尾字形的边缘遮罩，改由旧布局自检重建来修复连续翻页后的列错位。
- 翻页前检测 EPUB.js 实际列宽与当前视口宽度，检测到旧布局时按当前 CFI 自动重建分页。
- 加固阅读器父页面键盘处理，事件目标不是 HTML 元素时不再抛出 `matches()` 异常。
- 将 EPUB.js 废弃 `unload` 监听的过滤范围延长到异步 manager 启动完成，
  避免 Chrome 继续记录 Permissions Policy 提示。
- EPUB 上下滚动模式改用纸张右边缘的悬浮滚动条，不再占用正文宽度；正文行宽
  与分页模式保持一致，并支持拖动和点击轨道定位。
- 完成当前 EPUB 的 44 个 spine 项全量内容对比，文本、图片数量和分页边界均一致。
- 完成新导入 EPUB 的 26 个 spine 项、409 页全量内容对比；125,485 个正文
  字符和 19 个图片元素全部一致，未发现缺页、串页或栏边界越界。
- 扩展键盘处理：滚动模式支持上下方向键，EPUB iframe 内仍保留非 passive 监听。

### 验证

- 增加 EPUB 滚动模式键盘映射和 TXT 滚动布局测试。
- 使用隔离 Playwright 浏览器验证桌面、移动端、分页步长、章节边界、模式切换和字号重排。

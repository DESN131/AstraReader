# 变更记录

## 2026-11-20

### 阅读稳定性

- EPUB 分页改由 EPUB.js 使用 `gap: 0` 统一计算列宽，修复翻页时左侧重复、右侧裁切和内容漏过的问题。
- 字号、行距、段距或版心变化后强制按当前 CFI 重建视图，修复 EPUB 重新排版后容器宽度未同步的问题。
- 增加 EPUB 和 TXT 的上下滚动阅读方式；滚动位置通过 CFI 或字符偏移回写进度。
- 扩展键盘处理：滚动模式支持上下方向键，EPUB iframe 内仍保留非 passive 监听。

### 验证

- 增加 EPUB 滚动模式键盘映射和 TXT 滚动布局测试。
- 使用隔离 Playwright 浏览器验证桌面、移动端、分页步长、章节边界、模式切换和字号重排。

## 2026-11-19

### 文档

- 重整 README、架构、API、开发和部署文档。
- 新增文档索引、故障排查和变更记录。
- 补充数据模型、状态码、主题系统、安全边界和生产运维步骤。

### EPUB 阅读

- 首次打开自动跳过封面和前置页，定位到第一个可读正文节点。
- 移除旧版 EPUB.js `unload` 监听的兼容问题。
- 修复从书架客户端导航进入时空白的布局问题。
- 恢复 EPUB.js 正确的正文列宽与栏间距关系，避免一屏两列和内容截断。
- 在 EPUB iframe 内注册非 passive 键盘监听，修复方向键偶发失效。
- 保留父页面键盘处理，同时避免双重翻页。

### 主题

- 新增 VS Code 深灰主题。
- 主题设置改为浏览器级持久化并通过外部 store 同步。
- 书架、正文、目录抽屉和设置面板共享同一组 CSS 变量。

### 书库与数据

- 支持 EPUB 内置封面和 TXT 占位封面。
- 支持元数据编辑、手动封面、查重和永久删除。
- 支持 EPUB locations 缓存、CFI 进度、TXT 字符偏移和书签。
- 支持按书籍和日期累计阅读时长。
